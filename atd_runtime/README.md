# bobzhang/atd_runtime

The runtime library of the MoonBit code generated by `atdmbt`, the MoonBit
code generator of [bobzhang/atd](https://mooncakes.io/docs/bobzhang/atd)
(a port of [ATD](https://github.com/ahrefs/atd)). It has no dependencies
beyond the standard library.

Add it to the module containing the generated code:

```bash
moon add bobzhang/atd_runtime
```

and import it with the alias `atd_runtime` in the `moon.pkg` of the package
containing the generated code:

```
import {
  "bobzhang/atd_runtime" @atd_runtime,
}
```

It provides:

- readers (`(Json, Path) -> T raise JsonError`) and writers (`(T) -> Json`)
  for the basic types and combinators for lists, options, tuples,
  associative arrays and records, used by the generated code;
- `parse`, a JSON parser that keeps the textual representation of numbers
  (64-bit integers and exact floats), and `stringify`, which prints numbers
  like Yojson, for compatibility with the JSON produced by the other ATD
  code generators;
- `JsonError`, with the location (`Path`) of the error in the JSON value.
